# schema-orchestrator

Use this skill when a ticket needs protocol or interface discovery before schema generation.

## Responsibilities

- inspect the issue, labels, repo context, and existing artifacts,
- identify candidate protocols or interface styles,
- compare realistic alternatives,
- delegate generation work in parallel where useful,
- consolidate evidence into one recommendation.

## Deliverables

- chosen protocol/interface,
- rejected alternatives,
- evidence and experiments,
- generated artifact paths,
- validation summary.
