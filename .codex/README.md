# Uptempo `.codex`

This directory is the Codex-local skill surface for Uptempo.

It is intentionally separate from `.github/`:

- `.codex/` contains skills and bootstrap assets meant for Codex-driven issue execution.
- `.github/` contains repository automation, harness assets, Copilot instructions, and agent definitions.

If the two directories cover similar topics, treat `.codex/` as the runtime guidance for Codex sessions and `.github/` as adjacent project documentation or harness implementation details.
