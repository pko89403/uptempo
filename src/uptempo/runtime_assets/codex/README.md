# Uptempo runtime Codex assets

This directory contains the Codex-facing runtime assets shipped inside `src/uptempo/runtime_assets/`.

- `codex/skills/` contains skills and bootstrap assets meant for Uptempo issue execution.
- `.github/` remains separate for repository automation, harness assets, Copilot instructions, and agent definitions.

If the two directories cover similar topics, treat `src/uptempo/runtime_assets/codex/` as the runtime-owned asset surface and `.github/` as adjacent repository support tooling.
